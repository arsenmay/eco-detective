# ECO DETECTIVE: «Тайна пропавшей энергии»

Образовательная детективная игра для школьного конкурса по информатике в номинации «Геймификация энергосбережения». Первая версия — полностью проходимое дело с одним кабинетом информатики, персонажем и исследованием оборудования.

Локация вдохновлена средней школой №225 города Минска, но **планировка, интерьер и ситуации вымышлены**. Характеристики оборудования заданы для обучения и **не являются измерениями или сведениями о реальной школе**.

## Запуск

Нужен Node.js **22.12 или новее** и npm. Разработка и проверки выполнены на Node.js 24.19.0. Из каталога репозитория:

```sh
npm ci
npm run dev
```

Vite выведет адрес и выбранный порт в терминале. Если стандартный порт занят, он выберет свободный. Приложение работает в браузере: собственного backend, базы данных, регистрации и API-ключей нет. Интернет нужен для первоначальной установки npm-зависимостей; игра не загружает внешние шрифты, изображения или игровые данные.

```sh
npm run typecheck  # строгая проверка TypeScript
npm test          # расчёты, расследование, сохранения
npm run build     # проверка типов и production-сборка в dist/
npm run build:pages # сборка для адреса GitHub Pages /eco-detective/
```

Для локальной проверки обычной сборки: `npm run preview`. После `npm run build:pages` используйте `npm run preview -- --base=/eco-detective/` и открывайте путь `/eco-detective/` на указанном Vite порту. Каталог `dist/` можно разместить на статическом хостинге. Не открывайте `index.html` напрямую через `file://`: ES-модули требуют HTTP-раздачи.

## Открытие на других телефонах и компьютерах

Игрокам нужна только **постоянная HTTPS-ссылка**: приложение не требует Node.js, аккаунта или API-ключа. Публикация выполняется один раз; компьютер разработчика после неё можно выключить.

### GitHub Pages: автоматическая публикация

В `.github/workflows/deploy.yml` уже настроена публикация при отправке изменений в `main`. Workflow устанавливает зависимости, проверяет TypeScript, запускает тесты, собирает сайт с путём `/eco-detective/` и публикует `dist/`.

1. Отправьте файлы проекта в `arsenmay/eco-detective` на ветку `main`.
2. В репозитории откройте **Settings → Pages → Build and deployment → Source → GitHub Actions**. Это однократная настройка владельца. Не создавайте собственный токен для workflow: публикация использует встроенный `GITHUB_TOKEN`.
3. Откройте вкладку **Actions**, выберите **Publish ECO DETECTIVE**. Если предыдущий запуск завершился до включения Pages, нажмите **Re-run all jobs**. Также можно выбрать **Run workflow** на ветке `main`.
4. После успешного задания `deploy` откройте **View deployment**. Ожидаемый адрес для стандартной конфигурации репозитория: `https://arsenmay.github.io/eco-detective/`. Адрес станет доступен только после успешной публикации; созданный workflow сам по себе не означает, что сайт уже работает.

Каждое следующее обновление `main` автоматически обновляет сайт. Если GitHub сообщает, что Pages недоступны для текущего тарифа или приватности репозитория, можно воспользоваться другим статическим хостингом. Пользовательский домен не требуется.

### Ручная публикация на статическом хостинге

Выполните **`npm run build`** для сборки в корне сайта. Затем загрузите содержимое `dist/` в Netlify Drop или другой статический HTTPS-хостинг. На сервере `index.html`, `sw.js`, `manifest.webmanifest`, `assets/` и `icons/` должны лежать вместе. Не используйте сборку `build:pages` для корневого адреса Netlify: она рассчитана на подпапку `/eco-detective/`.

В архиве готового сайта `index.html` должен лежать непосредственно в корне. Не загружайте исходники или `node_modules` вместо содержимого `dist/`.

### Запуск значком и без интернета

- **Android / Chrome или Edge на ПК:** откройте опубликованную игру и нажмите **«Установить»**. Если браузер не показывает запрос, используйте его меню **«Установить приложение»**. Кнопка игры объясняет альтернативный способ, а не имитирует установку.
- **iPhone / iPad:** откройте игру в Safari → **«Поделиться» → «На экран Домой»**. Установка зависит от версии ОС и браузера.
- При первом открытии дождитесь надписи **«Готова к игре без интернета»**. Вся комната, интерфейс и данные дела сохраняются в кеш приложения, после чего доступен повторный запуск без сети. При блокировке или очистке хранилища потребуется загрузить игру заново.
- **«Поделиться игрой»** открывает системное меню отправки ссылки, копирует ссылку или показывает её для ручного копирования — в зависимости от возможностей браузера. Локальный `localhost` не предлагается как общедоступная ссылка.
- При обнаружении новой версии появляется предложение **«Обновить» / «Позже»**. Обновление по кнопке сначала сохраняет прогресс; игра не перезагружается автоматически во время расследования.

Прогресс на телефоне и ПК остаётся отдельным. PWA не добавляет облачную синхронизацию.

## Как играть

1. Нажмите «Начать расследование». Если сохранение уже существует, игра попросит подтвердить его замену. «Продолжить» восстанавливает позицию, свидетельства и результат отчёта.
2. Двигайтесь **WASD** или **стрелками**. На телефоне используйте сенсорную крестовину. Движение ограничено стенами и мебелью; диагональ не увеличивает скорость.
3. Подойдите к устройству с бирюзовой меткой. Нажмите **E**, саму метку или кнопку «Осмотреть». Осмотр на расстоянии недоступен.
4. Изучите компьютеры, проектор и сетевой узел — три обязательные группы свидетельств. Всего в комнате шесть объектов; их записи доступны в блокноте после осмотра.
5. Откройте «Предварительный отчёт», сравните расход и выберите причину. Неверная гипотеза получает объяснение, после чего можно попробовать снова. Верный ответ завершает дело; остальные устройства можно изучать дальше.

**Esc** закрывает панель; из комнаты возвращает в меню. При открытой панели и потере фокуса движение приостанавливается. Настройки позволяют уменьшить анимации и скрыть подсказки клавиш. Три достижения привязаны к текущему прохождению и работают уже сейчас.

## Учебная модель энергии

Отдельный модуль `src/systems/energy.ts` вычисляет:

```text
E за день = P (Вт) × t (ч) × количество / 1000
E за учебный месяц = E за день × рабочие дни
```

В деле используются **20 учебных дней**. Для круглосуточного сетевого узла тоже показывается расход за выбранные 20 дней, а не за полный календарный месяц. У компьютеров и мониторов моделируется интервал ожидания отдельно от активных уроков. Входные числа проверяются: мощность неотрицательная, время в диапазоне 0–24 часа, количество положительное целое, рабочие дни — целое от 0 до 31.

| Группа | Количество × мощность | Часы в день | кВт·ч за 20 дней |
| --- | ---: | ---: | ---: |
| Учебные системные блоки в ожидании | 6 × 80 Вт | 10 | 96 |
| Учебные мониторы в ожидании | 6 × 20 Вт | 10 | 24 |
| Проектор во время уроков | 1 × 300 Вт | 2 | 12 |
| Освещение | 4 × 18 Вт | 8 | 11,52 |
| Компьютер учителя | 1 × 65 Вт | 2 | 2,6 |
| Сетевой узел | 1 × 12 Вт | 24 | 5,76 |

Сумма модели — **151,88 кВт·ч**. Правильный вывод основан на лишнем времени ожидания и возможности безопасно изменить расписание. Проектор мощнее одного компьютера, но уже работает только на уроках; сетевой узел обеспечивает необходимую связь.

Сокращение ожидания компьютеров и мониторов с 10 до 2 часов даёт **96 кВт·ч потенциальной экономии** за 20 дней: 76,8 + 19,2. Это сравнение двух заданных режимов, а не достигнутая экономия. Рекомендация для освещения учитывает достаточную видимость и не входит в итоговый расчёт отчёта. Игра не управляет настоящим оборудованием; реальные изменения выполняют ответственные сотрудники.

## Архитектура

```text
src/
  main.ts                     запуск Phaser и интерфейса
  pwa.ts                      установка, отправка ссылки, кеш и обновления
  vite-env.d.ts               типы Vite и PWA
  types.ts                    контракты данных и управления
  style.css                   адаптивный интерфейс, панели и переходы
  data/schoolCase.ts          оборудование, режимы, гипотезы одного дела
  game/createRoom.ts          конфигурация Phaser и масштабирование
  game/RoomScene.ts           сцена, физика, клавиатура, пауза
  game/Player.ts              персонаж и нормализованное движение
  game/roomArtwork.ts         оригинальный процедурный интерьер
  game/InteractionSystem.ts   расстояние взаимодействия и метки
  systems/energy.ts           расчёт кВт·ч и потенциальной экономии
  systems/investigation.ts    свидетельства и проверка отчёта
  systems/storage.ts          версия/валидация сохранений и настроек
  ui/GameUI.ts                меню, HUD, блокнот, отчёт, touch-кнопки
  ui/icons.ts                 локальные SVG-иконки
tests/                        автоматические проверки логики
public/favicon.svg            оригинальный значок сайта
public/icons/                 оригинальные SVG/PNG-иконки приложения и iOS
vite.config.ts                путь публикации, манифест и офлайн-кеш
scripts/build-pages.mjs        сборка для Pages на Windows/macOS/Linux
.github/workflows/deploy.yml   автоматическая проверка и публикация
```

Стек: **TypeScript, Phaser 3, Vite, HTML5 и CSS3**. PWA-манифест и service worker генерируются `vite-plugin-pwa` / Workbox при сборке; в режиме разработки офлайн-кеш отключён, чтобы не сохранять устаревшие исходники. Комната и персонаж рисуются программно; платные ресурсы не используются. Canvas-масштабирование сохраняет обзор всей комнаты на разных экранах. DOM-панели имеют клавиатурный фокус, семантические кнопки, пояснения и поддержку уменьшения анимаций.

## Сохранения

Прогресс автоматически хранится в `localStorage` под ключом `eco-detective:progress:v1`, настройки — `eco-detective:settings:v1`. Сохранения принадлежат конкретному браузеру и origin, поэтому другой порт или домен имеет отдельный прогресс. Очистка данных браузера удалит его. Повреждённые или несовместимые записи проверяются; неизвестные улики и неверные координаты не принимаются. При блокировке хранилища игра продолжает работать и явно сообщает, что прогресс остаётся только в сессии.

## Границы прототипа

Доступно только **«Дело №001: Школьная аномалия»** и одна комната. Экран выбора дела работает; будущие дела отмечены как отсутствующие. Реальных фотографий школы, других локаций, звука, переназначения клавиш, облачной синхронизации, настоящих измерений и физического переключения оборудования пока нет. Персонаж остаётся в кабинете; дверь является частью оформления.

- Сенсорные события: движение и осмотр на мобильном экране; проверены ширины 390 и 320 пикселей без горизонтального переполнения, а также работа при блокировке `localStorage`.
- PWA: сборка в подпапке `/eco-detective/`, загрузка PNG-иконок, соответствие `start_url` и scope, отсутствие ошибок установимости в обычном профиле Chromium. Проверены кнопка запроса установки и инструкция для браузеров без такого запроса.
- Офлайн: после загрузки кеша сеть отключалась средствами браузера; перезагрузка, продолжение сохранённого дела, движение и сведения об устройстве работают. Повторный запуск проверен на ПК и мобильном экране.

Vite выдаёт предупреждение о размере основного бандла с Phaser (около 1,28 МБ до gzip, около 356 кБ после). Сборка завершается успешно. Установка на физический смартфон и реальные измерения энергопотребления не проверялись; тест мобильного браузера выполнялся в эмуляции Chromium. Публикация в интернете проверяется отдельно после успешного GitHub Actions deployment.
