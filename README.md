# ECO DETECTIVE 2.0: «Тайна пропавшей энергии»

Образовательная детективная игра для конкурса по информатике «Геймификация энергосбережения». Существующий проект на TypeScript, Phaser 3 и Vite расширен до кампании из пяти расследований: исследование помещений, блокнот, анализ данных, гипотезы, безопасные планы и отчёты.

**Игра опубликована:** [открыть ECO DETECTIVE 2.0](https://arsenmay.github.io/eco-detective/). На телефоне и ПК достаточно открыть ссылку.

**Планировка, интерьеры и энергетические ситуации условной СШ №225 Минска вымышлены.** Характеристики и графики не являются измерениями реальной школы. Игра не управляет настоящим оборудованием. Тепловизор показывает учебную визуализацию, а не реальные снимки.

## Запуск

Нужны Node.js **22.12 или новее** и npm. В каталоге проекта:

```sh
npm ci
npm run dev
```

Откройте адрес из вывода Vite. Если порт занят, выбирается свободный. Для телефона в той же локальной сети используйте сетевой адрес Vite, а не `localhost` другого устройства. При проблемах проверьте брандмауэр. Доступ из интернета обеспечивает публикация, описанная ниже.

Игрокам Node.js не нужен: достаточно опубликованной HTTPS-ссылки. Backend, базы данных, регистрации, платных ресурсов и API-ключей нет. Графика, данные и звуки локальные.

```sh
npm run typecheck    # TypeScript
npm test             # модели, кампания, награды, сохранения, камера и управление
npm run build        # проверка типов и production-сборка в dist/
npm run build:pages  # сборка для /eco-detective/
npm run preview      # локальная проверка production-сборки
```

После сборки Pages для preview в bash:

```sh
npm run build:pages
DEPLOY_BASE=/eco-detective/ npm run preview
```

PowerShell: `$env:DEPLOY_BASE='/eco-detective/'; npm run preview`. Открывайте путь `/eco-detective/` на выданном Vite порту. Сама команда `build:pages` работает на Windows, macOS и Linux. Не открывайте `index.html` через `file://`: нужна HTTP-раздача.

## Управление и прохождение

1. **«Новая игра»** начинает кампанию; замена сохранения требует подтверждения. **«Продолжить»** восстанавливает текущее дело, позицию, источники, задания и план.
2. ПК: **WASD / стрелки**, взаимодействие **E**. Телефон: **джойстик слева внизу**, крупная кнопка осмотра справа. Диагональ не ускоряет движение, отклонение регулирует скорость, чувствительность в настройках — **0,5–1,5**.
3. Подойдите к бирюзовой метке. Осматривать можно клавишей, меткой или кнопкой; удалённый осмотр недоступен. Стены и мебель имеют столкновения.
4. Изучите показания и нажмите **«Записать улику»**. Простое открытие панели не записывает находку. В блокноте доступны наблюдения и отметки подозрений.
5. Соберите обязательные источники и пройдите **анализ данных**. Ошибка получает объяснение и повторную попытку.
6. Подтвердите **гипотезу**; в финале нужны несколько независимых причин. После анализа и верного вывода открывается **лаборатория решений**.
7. Настройте расписание, температуры или модернизацию. Предварительный расчёт меняется сразу; при проверке учитываются цель, безопасность, комфорт и бюджет.
8. Принятый план завершает дело, открывает подробный отчёт и следующее расследование. Кнопка **«Сравнить другой план»** доступна и на телефоне. Пройденные дела доступны на карте; альтернативный план не отменяет прежний успех.

**Esc** закрывает панель, а в комнате возвращает в меню. Панели приостанавливают движение. Отпускание пальца, `pointercancel`, потеря захвата, фокуса и сворачивание сбрасывают управление. Одним пальцем можно двигаться, вторым — осматривать; открытие окна останавливает персонажа.

Мобильная камера следует за персонажем и показывает увеличенную часть мира **1120 × 760**. Мир не уменьшается целиком до ширины телефона. **«+» / «−»** регулируют масштаб **0,85–1,25**. Поворот пересчитывает viewport и границы; портрет разрешён, горизонталь показывает больше комнаты.

Компактный HUD оставляет место игре, второстепенные сведения открываются через блокнот и панели. Используются `100dvh` и safe-area; мобильные окна занимают доступный экран и прокручивают свой текст. **«Полный экран»** запрашивает API браузера; при запрете или отсутствии API сохраняется обычный игровой макет страницы.

Звуки Web Audio выключены по умолчанию. Настройки также предлагают уменьшение анимации и подсказки. Переназначения клавиш нет.

## Учебная модель электричества

`src/systems/energy.ts`:

```text
E за день = P (Вт) × t (ч) × количество / 1000
E за период = E за день × количество дней
```

Везде используются **20 выбранных учебных суток**, включая круглосуточные устройства, а не полный календарный месяц. Ватты / кВт — мощность, кВт·ч — энергия за время. Проверяются конечность, часы, количество, дни и переполнение.

| Дело | Исходные мощности и время | кВт·ч за 20 дней | Цель и ограничения |
| --- | --- | ---: | --- |
| №001 | Блоки 6×80 Вт×10 ч; экраны 6×20 Вт×10 ч; проектор 300 Вт×2 ч; свет 72 Вт×8 ч; учитель 65 Вт×2 ч; сеть 12 Вт×24 ч | 151,88 | Экономия ≥84, нужные режимы сохранены |
| №002 | Окна 108 Вт×10 ч; внутри 144 Вт×10 ч; лестница 72 Вт×12 ч; аварийный свет 12 Вт×24 ч | 73,44 | Экономия ≥20, достаточный свет и аварийная готовность |
| №003 | Холодильник 120 Вт×24 ч; морозильник 160 Вт×24 ч; вытяжка 300 Вт×10 ч; мармит 1200 Вт×5 ч; свет 180 Вт×10 ч; печь 2000 Вт×3 ч | 470,4 | Экономия ≥64, бюджет ≤5, безопасные операции |
| №004 | Отдельная модель теплопередачи | Электричество этих источников не моделируется | См. тепловую модель |
| №005 | Кабинет 151,88 + холл 73,44 + кухня 470,4 + сервер 9,6 | 705,32 | ≥120 электрических и отдельно ≥40 тепловых кВт·ч экономии; бюджет ≤10; безопасный приоритет |

Блоки и мониторы моделируют **ожидание отдельно от активных уроков**. Самый мощный прибор не обязательно расходует энергию без пользы: проектор уже работает только на уроках, связь нужна круглосуточно.

Холодильные 120 и 160 Вт — **средние мощности с учётом циклов компрессоров**. Финальные агрегаты имеют эквивалентную среднюю суточную мощность; реальные внутри модели интервалы отражает график. Паспорт хранения не дублирует кухонный расход.

## Тепловая модель

```text
Q тепла (кВт·ч) = U × A × (T внутри − T снаружи) × t / 1000
U — Вт/(м²·К), A — м², t — часы
```

Разность °C численно равна разности К. Снаружи +4 °C, время **160 часов** — 20 дней по 8. Исходно кабинеты +22 °C, зал +20 °C.

| Элемент | U | A | ΔT | Потери тепла за 160 ч |
| --- | ---: | ---: | ---: | ---: |
| Окна А | 3 | 8 м² | 18 К | 69,12 кВт·ч |
| Окна Б | 1,3 | 8 м² | 18 К | 29,952 кВт·ч |
| Окна зала | 3 | 16 м² | 16 К | 122,88 кВт·ч |
| Дверь зала | 4 | 4 м² | 16 К | 40,96 кВт·ч |
| **Сумма** | | | | **262,912 кВт·ч тепла** |

Меры уменьшают U: А до 1,4 за 3 кредита, зал до 1,5 за 4, дверь до 2 за 2. Цель — ≥80 кВт·ч тепловой экономии при бюджете 6. Температуры задания: кабинеты **20–22 °C**, зал **18–20 °C**; это условия игры, а не универсальные нормативы.

Модель стационарная, учитывает только четыре элемента при постоянной температуре. Не учтены стены, вентиляция, солнце, люди, теплоёмкость, погода, источник отопления и КПД. Это не полный аудит. Тепло не приравнивается к электричеству; выход, воздухообмен и комфорт сохраняются. Реальные изменения согласуются со специалистами.

## Сохранения и миграция

`localStorage` текущего браузера и сайта:

- `eco-detective:campaign:v2` — текущее дело, отдельные позиции, улики, ответы, гипотезы, планы, завершение и идентификаторы наград.
- `eco-detective:progress:v1` — прежний прогресс, сохраняется резервом при миграции.
- `eco-detective:campaign:v2:recovery` — копия повреждённой v2 перед её явной заменой, для ручной диагностики и восстановления.
- `eco-detective:settings:v1` — настройки; новым полям назначаются значения по умолчанию.

Старые улики, позиция и верный отчёт переносятся. **Старый безопасный применённый план остаётся завершённым даже ниже новой цели.** Отчёт без плана сохраняет решённую гипотезу; новые этапы выполняются для следующего дела. Повреждённые записи проверяются; доступный валидный v1 восстанавливается с сообщением. Перед явной заменой повреждённая v2 копируется в recovery. Если резерв нельзя записать из-за квоты, исходная запись не заменяется. При ограниченном хранилище игра доступна, но предупреждает о невозможности сохранения.

Дела не смешивают позиции и задачи; повторные действия и перезагрузка не дублируют XP. Очистка данных сайта удаляет прогресс. На телефоне и ПК сохранения отдельные: аккаунтов, облачной синхронизации и экспорта нет. Другой домен не переносит данные автоматически.

## Публикация и PWA

Workflow `.github/workflows/deploy.yml` выполняет `npm ci`, TypeScript, тесты, `build:pages` и deployment. Путь — **`/eco-detective/`**, целевой адрес — `https://arsenmay.github.io/eco-detective/`. Публичная прежняя версия или HTTP 200 не подтверждают публикацию обновления: нужны deployment нужного commit и запуск самой игры.

1. Проверьте **Settings → Pages → Build and deployment → Source → GitHub Actions**. В подключённом репозитории этот источник уже включён; повторная настройка не требуется.
2. Отправьте изменения в `main`; при необходимости запустите **Publish ECO DETECTIVE** вручную.
3. После успешного `deploy` откройте **View deployment**, проверьте меню, комнату и осмотр.

**Deploy from a branch** с исходниками не собирает игру: браузер не компилирует `/src/main.ts`. Production HTML должен ссылаться на `assets/`. Источник GitHub Actions для текущего репозитория подтверждён через API. Новые собственные API-ключи не нужны.

Для корневого HTTPS-хостинга выполните `npm run build` и загрузите **содержимое `dist/`**; не исходники или `node_modules`. Pages-сборка не подходит для корня другого сайта. Рядом должны лежать `index.html`, `sw.js`, `manifest.webmanifest`, `assets/` и `icons/`.

**Установка:** поддерживаемые Android/Chrome и браузеры ПК показывают «Установить» или пункт меню. В iOS/Safari — «Поделиться → На экран Домой». При недоступном системном запросе игра объясняет способ. «Поделиться игрой» вызывает системное меню, копирует или показывает ссылку; локальная ссылка не выдаётся за публичную.

**Офлайн:** дождитесь «Готова к игре без интернета». Production service worker кеширует код, все пять дел, графику и значки. После очистки данных нужна повторная загрузка. `npm run dev` не включает production-кеш. PWA требует HTTPS либо разрешённого локального контекста.

**Обновление:** «Обновить» / «Позже» сохраняет прогресс перед перезагрузкой. Принудительного сброса активного расследования нет. Manifest, scope, start_url и offline fallback соответствуют пути сборки.

## Проверки и ограничения

Итоговые проверки прошли: **93 теста**, `npm run typecheck`, `npm run build`, `npm run build:pages`. Зависимости повторно установлены через `npm ci` с доступным кешем `/tmp/eco-detective-npm-cache`. Тесты покрывают формулы, безопасные альтернативы, пять цепочек, гипотезы, открытие, награды, достижения, независимые позиции, миграцию, повреждения, графики, достижимость, камеру и джойстик. Подробности в [отчёте](docs/IMPLEMENTATION_REPORT.md).

Chromium/Playwright проверил мобильные размеры **320, 375, 390, 430, 768, 1024** и горизонтальный **844 × 390**, камеру, панели, переполнение, CDP-мультитач, отмену/отпускание, blur и паузу. Полностью пройдены **все пять дел через WASD** с записью 39 улик, неверным/верным анализом и гипотезой, небезопасным/безопасным планом. Проверены отчёты, отсутствие повторного XP, перезагрузка и повторный вход в пять завершённых дел, предупреждение восстановления и сохранение резервов. Production PWA проверена для `/` и `/eco-detective/`: manifest, scope, декодирование значков, кеш SVG, офлайн-перезагрузка ПК и мобильного интерфейса, управление, запись улик, восстановление пяти пройденных дел и отчётов. Chromium не обнаружил препятствий для установки; нативная установка ОС не выполнялась. Публичная версия 2.0 также проверена: запуск, карта пяти дел, осмотр и запись, управление, продолжение после офлайн-перезагрузки на ПК и мобильном viewport, копирование публичной ссылки. Ошибок браузера и ресурсов нет.

Физические Android/iPhone, установка на них, Safari, Firefox и Edge не проверены в текущей среде. Испытаний длительности со школьниками не было. Нет настоящих фотографий и измерений школы, управления устройствами, мультиплеера, облачной синхронизации и переназначения клавиш. Phaser увеличивает главный chunk; предупреждение Vite о размере не является замером FPS телефона.
